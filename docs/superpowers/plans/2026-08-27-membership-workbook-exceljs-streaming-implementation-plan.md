# Membership Workbook ExcelJS Streaming Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the memory-resident membership workbook builder with an ExcelJS streaming writer that produces and verifies one complete 40,000-row-per-business-sheet XLSX before atomically replacing the requested workbook.

**Architecture:** Install ExcelJS 4.4.0 in an isolated `loadtest` Node package. Read each PostgreSQL CSV as an async stream, validate and transform one record, commit one Excel row, and discard the record. Reopen the staging workbook with ExcelJS `WorkbookReader`, verify it to EOF with bounded memory, render only retained top-row samples, and let PowerShell replace the original file only after every gate passes.

**Tech Stack:** PowerShell 7, bundled Node.js, pnpm, ExcelJS 4.4.0 streaming writer/reader, PostgreSQL `psql`, existing `@oai/artifact-tool` only for tiny preview samples.

- [ ] **Step 3: Replace full-file CSV loading with an async generator**

Implement this public contract in the builder:

```javascript
export async function* streamCsvObjects(filePath) {
  const parser = new StreamingCsvParser(filePath);
  let headers = null;
  let dataRow = 0;
  for await (const cells of parser.rows()) {
    if (headers === null) {
      headers = cells;
      assertUniqueHeaders(headers, filePath);
      continue;
    }
    if (cells.length !== headers.length) {
      throw new Error(`CSV row ${dataRow + 2} has an unexpected column count: ${filePath}`);
    }
    dataRow += 1;
    yield Object.fromEntries(headers.map((header, index) => [header, cells[index]]));
  }
  if (headers === null) throw new Error(`CSV is empty: ${filePath}`);
}
```

`StreamingCsvParser.rows()` must consume `fs.createReadStream(filePath, { encoding: "utf8" })`, preserve quote state across chunks, convert doubled quotes to one quote, and emit a row only after a newline outside quotes.

```javascript
async function writeCsvWorksheet({ workbook, name, csvPath, columns, expectedRows, views }) {
  const worksheet = workbook.addWorksheet(name, { views });
  worksheet.columns = columns.map(toExcelColumn);
  const header = worksheet.addRow(columns.map((column) => column.header));
  applyHeaderStyle(header);
  header.commit();
  let count = 0;
  for await (const record of streamCsvObjects(csvPath)) {
    const values = columns.map((column) => normalizeCellValue(column.value(record, count), column));
    const row = worksheet.addRow(values);
    applyColumnFormats(row, columns);
    row.commit();
    count += 1;
    if (count % 5000 === 0) logMemory(`${name}: ${count}/${expectedRows}`);
  }
  requireExactCount(count, expectedRows, name);
  worksheet.autoFilter = `A1:${columnName(columns.length - 1)}${expectedRows + 1}`;
  worksheet.commit();
  return count;
}
```
