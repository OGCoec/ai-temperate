# 管理员 H5 输入方框修复实施计划

**目标：** 修复管理员 H5 首次注册与登录时邮箱、手机号、验证码、密码输入框丢失视觉边界的问题。

1. 为管理员身份组件写静态回归用例，要求其复用具备组件内样式的 `IdentifierFields`，并同时渲染邮箱与手机号。
2. 将 `AdminIdentityForm` 改为组合两个 `IdentifierFields`，保留既有双向绑定和错误信息契约。
3. 为验证码和密码字段建立组件内 `auth-control` 方框，替换页面内裸输入框。
4. 在管理员页面接入三个组件，并在加载时使用既有国家识别接口为手机号选择提供建议值。
5. 在用户明确进入第二阶段后，执行授权的 Node 回归用例与 H5 构建/人工验收；测试环境不得连接生产认证服务。

本计划不改动管理员 API、hCaptcha 流程、Cookie/Token 传输协议或普通用户登录规则。
