# 普通用户前端本地认证预览能力移除设计

## 目标

彻底移除普通用户前端中的本地认证预览能力。新前端不再提供“本地预览登录后页面”入口，也不再允许通过 URL 参数、本地存储或模拟用户资料绕过真实认证流程。

真实用户登录成功后的个人中心页面继续保留，管理员前端和 Java 后端不在本次修改范围内。

## 当前行为

本地预览入口不提交账号或密码，也不调用后端登录接口。点击入口后，前端会：

1. 在本地存储中写入预览启用标记。
2. 在本地资料存储中写入固定的模拟昵称、邮箱和手机号。
3. 跳转到真实个人中心路由。
4. 在会话恢复、个人资料读取和退出登录时走本地预览分支，跳过对应后端请求。

登录页自身仍可能独立发起 CSRF、PreAuth 和 WebRTC 风控初始化请求，这些请求不属于本地预览登录行为。

## 采用方案

采用物理删除方案，不保留关闭开关或构建时隐藏逻辑：

- 删除本地预览会话模块。
- 删除登录页预览按钮、状态、方法和相关依赖。
- 删除启动会话页对预览 URL 参数的识别。
- 删除会话恢复、个人资料读取、退出登录和全设备退出中的预览分支。
- 删除 Cookie 作用域迁移对预览会话的清理依赖。
- 更新前端 README 和契约测试，移除对预览能力存在性的断言，并增加关键源码不再引用预览能力的约束。

## 认证与页面行为

- 普通用户只能通过真实登录流程建立认证状态。
- 未登录用户访问受保护页面时仍由现有页面守卫跳转至登录页。
- H5 会话恢复继续调用后端引导接口；Android 继续检查本地完整凭据。
- 真实登录成功后仍跳转到个人中心。
- 个人中心继续调用 `/api/users/me` 获取当前用户资料。
- 退出登录和退出所有设备继续调用真实会话接口。
- `authUiPreview`、`uiPreview` 和 `mockAuth` 参数不再被读取。

## 兼容与清理

旧版本写入的 `ait.auth.ui-preview.enabled.v1` 本地标记在新版本中不会再被读取，因此不能继续启用预览或绕过登录。为避免为了清理一个无效值而保留预览专用代码，本次不增加迁移逻辑；该无效本地值可以随站点数据清理自然消失。

## 错误处理

移除预览分支后，所有认证和个人资料错误继续沿用现有真实会话错误处理：

- 终止型会话错误清除本地会话并返回登录页。
- 可恢复的网络错误保留现有重试提示。
- 退出登录仍在现有 `finally` 清理本地会话。

## 验证范围

本次会同步更新相关前端测试代码，但按照项目第一阶段规则不自动运行测试、编译或打包。代码交付时将明确列出未执行的验证，等待用户决定是否进入第二阶段安全测试。

## 非目标

- 不删除真实个人中心页面。
- 不修改管理员前端。
- 不修改 Java Controller、Service、Mapper 或认证接口。
- 不调整登录页其他网络初始化、安全校验或真实登录流程。
