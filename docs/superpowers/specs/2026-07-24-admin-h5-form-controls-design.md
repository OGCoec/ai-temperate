# 管理员 H5 输入方框修复设计

管理员 UniApp 页面必须让每个输入组件自行承载方框的布局与状态样式，不能依赖页面父级样式跨组件生效。管理员身份流程同时展示邮箱、国家/地区与手机号；双重验证展示两个六位验证码；密码流程展示密码与确认密码或登录密码。

复用 `myuniappadmin/components/auth/identifier-fields.vue` 作为管理员身份输入的内部实现，因为它已经在组件内引入 `auth-controls.scss` 并使用 `auth-control`、`auth-control-input` 与 `phone-row` 结构。验证码和密码组件采用相同的本地样式边界。页面只负责编排注册、验证、登录状态和 API 调用。

H5 通过可见边框、固定最小高度、横向区号与手机号、焦点和错误态验收；Android 复用同一组件结构，不改变认证协议或服务端逻辑。
