# ChatGPT Markdown 渲染行为研究

## 研究范围

本研究只覆盖 ChatGPT 对普通助手文本执行的 Markdown 到前端语义结构转换，不覆盖整页布局、账号能力、网络协议、后端实现或 ChatGPT 私有源码。

研究使用一个新建的普通 ChatGPT 对话发送固定语法矩阵，再读取生成完成后的可访问性 DOM 快照。测试发生于 2026-08-02。账号只用于打开普通聊天，账号历史与本研究无关。

## 已验证的转换规则

| Markdown 输入 | 已观察到的语义结果 | 迁移要求 |
| --- | --- | --- |
| `# 文本` | 一级标题，heading level 1 | 生成 H1 语义节点 |
| `## 文本` | 二级标题，heading level 2 | 生成 H2 语义节点 |
| `### 文本` | 三级标题，heading level 3 | 生成 H3 语义节点 |
| 普通连续文本 | paragraph | 生成段落节点 |
| `**粗体**` | strong | 生成强强调节点 |
| `*斜体*` | emphasis | 生成强调节点 |
| `~~删除线~~` | deletion | 生成删除线节点 |
| `` `inlineCode()` `` | code | 生成行内代码节点 |
| `[OpenAI](https://openai.com)` | link，保留目标 URL | 生成安全链接组件 |
| `- 项目` | list，项目内容为 paragraph | 生成无序列表；保留嵌套层级 |
| `1. 项目` | list，项目内容为 paragraph | 生成有序列表；保留顺序 |
| `> 引用` | blockquote 内含 paragraph | 支持引用嵌套 |
| `---` | separator | 生成水平分隔线 |
| 围栏代码块 ` ```java ` | 显示语言标题 `Java`、复制按钮和代码内容 | 使用专用代码块组件，不作为普通段落 |
| GFM 表格 | table、rowgroup、row、columnheader、cell | 使用语义表格及横向溢出容器 |
| `- [x]` / `- [ ]` | disabled checkbox，分别为选中和未选中 | 任务框只读，禁止在回复中交互修改 |
| `...` / `..` | 普通文本 | 点号本身没有特殊转换 |
| `\*文本\*` | 显示字面量星号 | 支持反斜杠转义 |
| 原始 `<span ...>` | 原样显示为文本，没有创建可执行 HTML 节点 | 必须禁用原始 HTML |

可访问性快照没有区分两个 `list` 节点的实际标签名，但结合输入语法可以确认页面分别表现为无序列表和有序列表。迁移实现应使用等价的 `ul` 与 `ol` 语义，而不是用普通 `div` 模拟。

## 代码块的专用行为

输入的语言标记是小写 `java`，界面显示为标题化的 `Java`。代码内容位于独立代码区域，顶部有复制按钮。由此可确定：

1. 围栏后的信息字符串用于选择语言标签和高亮规则，不是代码正文。
2. 没有语言信息时仍应生成代码块，但语言标题应省略或显示稳定的通用名称。
3. 未知语言必须降级为纯文本代码，不能导致整条消息失败。
4. 复制操作只复制代码正文，不应复制语言标题或按钮文字。

本次在停止浏览器检查前没有提取高亮跨度、主题色和精确 CSS，因此不能声称已经复制 ChatGPT 的语法高亮配色。

## 表格的专用行为

测试表格生成了独立表头与表体，并额外出现“复制表格”按钮。列对齐标记没有在可访问性快照中暴露计算样式，因此左、中、右对齐的精确 CSS 尚未验证。迁移时应保留解析后的对齐元数据，再由组件设置受控样式。

## 流式行为证据

本次抓取了两个时间点：

- 提交后约 250ms：页面只有用户消息区域和“停止回答”控制，尚未出现可读的助手 Markdown 节点。
- 随后约 900ms：回答已经完成，所有标题、列表、代码块、表格和任务框均为最终结构。

因为回答完成得很快，本次没有捕获到半个 `**`、未闭合代码围栏或半行表格正在显示的中间 DOM。因此“ChatGPT 对未闭合 Markdown 的精确临时结构”仍是未验证项，不能凭经验伪造结论。

试点实现应采用确定的本地规则：每次收到文本 delta 后解析当前累计缓冲区；解析器允许未闭合结构临时延伸到缓冲区末尾；收到终态后执行一次最终解析。解析失败时仅把当前内容作为纯文本显示，不能让消息列表崩溃。

## 安全边界

- 禁止把模型输出直接交给 `v-html` 或 `innerHTML`。
- 原始 HTML、脚本、事件属性和自定义标签一律作为文本处理。
- 链接只允许受控协议；拒绝 `javascript:`、`data:` 等危险协议。
- 外部链接增加 `rel="noopener noreferrer"`，是否新窗口打开由产品统一决定。
- 任务列表中的复选框必须禁用。
- 代码块内容只作为文本着色，禁止执行。

## 本次未验证项

- H4-H6、Setext 标题、脚注、数学公式、Mermaid、图片和自动链接。
- 未闭合强调、未闭合代码围栏和流式半行表格的真实 ChatGPT 中间 DOM。
- 代码高亮所用库、具体 token class、主题色和复制成功反馈。
- 表格的精确对齐、边框、滚动条和响应式 CSS。
- ChatGPT 灰度发布或不同账号实验导致的实现差异。
