# ChatGPT Markdown 消息表面拓扑

## 目标表面

本次定向克隆只有“助手回复正文”一个页面区域，不克隆 ChatGPT 顶栏、侧栏、输入框、账号菜单或历史会话。

```text
消息滚动容器
└── 对话轮次
    ├── 用户消息（保持纯文本）
    └── 助手消息
        ├── 普通 Markdown 节点
        │   ├── 标题 / 段落 / 强调 / 链接
        │   ├── 无序列表 / 有序列表 / 引用 / 分隔线
        │   └── 行内代码
        ├── 专用代码块组件
        │   ├── 语言标题
        │   ├── 复制按钮
        │   └── 高亮代码正文
        ├── 专用表格组件
        │   ├── 表头 / 表体
        │   ├── 列对齐
        │   └── 复制表格按钮
        └── 只读任务列表
```

## 交互模型

- 普通节点：静态。
- 助手消息：由 SSE 文本 delta 驱动更新。
- 代码复制与表格复制：点击驱动，只写入剪贴板，不改变消息内容。
- 任务列表：只读，不允许点击改变状态。
- 链接：点击驱动，必须先通过协议白名单。

## 项目内接入位置

现有 `fornted/components/user/workspace/user-chat-panel.vue` 在助手消息中直接输出 `message.responseText`，所以当前全部 Markdown 都按纯文本展示。流式接收逻辑已经把每个 delta 追加到同一个 `responseText` 字符串。

试点迁移只替换助手消息正文展示：

```text
message.responseText
-> 安全 Markdown 解析器
-> 受控节点树
-> Markdown 消息组件
```

用户消息继续使用纯文本，附件、SSE 生命周期、停止生成、保存状态和错误提示均不进入本次范围。
